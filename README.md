# MotoReserve - Portal Ogłoszeń Motoryzacyjnych

## O projekcie
MotoReserve to w pełni funkcjonalna aplikacja webowa typu marketplace, inspirowana serwisem Otomoto. Projekt został zrealizowany w ramach zaliczenia przedmiotu Technologie Webowe. System umożliwia przeglądanie ofert sprzedaży pojazdów, ich filtrowanie oraz zarządzanie treścią poprzez panel administracyjny.

## Technologie
### Backend:
- **ASP.NET Core 8.0 MVC**
- **Entity Framework Core** (ORM)
- **SQL Server** (Baza danych)
- **Identity Foundation** (Autentykacja i Autoryzacja)

### Frontend:
- **HTML5** (Semantyczny kod zgodny z W3C)
- **CSS3 / Tailwind CSS** (Responsywny Design - RWD)
- **Vanilla JavaScript** (Interaktywność, obsługa galerii)

## Kluczowe funkcjonalności
- **System Ogłoszeń:** Przeglądanie ofert z podziałem na kategorie.
- **Wyszukiwarka i Filtry:** Filtrowanie po cenie, roku produkcji, przebiegu i marce.
- **Panel Administratora (CMS):**
  - Logowanie zabezpieczone hasłem.
  - Pełny CRUD (Create, Read, Update, Delete) dla ogłoszeń.
  - Upload i zarządzanie zdjęciami pojazdów.
- **Responsywność:** Aplikacja w pełni dostosowana do urządzeń mobilnych (Mobile First Design).
